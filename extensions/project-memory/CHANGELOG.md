# Changelog

## 1.1.1

A record is referred to by its name, and this stops showing the opposite.

The line every session ends on — *say what you wrote, in one line* — was
illustrated with a bare key, which is the one thing that line must not be. A key
is an address: it says nothing about what it points at, and the person reading
it cannot open it. The example now names the record and carries the address in
the link, which is what the sentence was asking for all along.

How that link is spelled is Sync's own rule and is stated in the instructions
every session already reads, so this no longer restates it. Two copies of one
spelling is one of them going out of date.

## 1.1.0

Questions get a section, and answering one stops being an edit.

Four of the five kinds here are claims: somebody reads them. The fifth is
addressed to somebody — it waits, and until now the only way to settle it was to
find the record among everything else the project holds and type into two fields
whose names nobody remembers. So the choices offered by whoever asked are now
controls: one of them where one may be taken, a set of them where several may,
each written the moment it is pressed, with the digits `1`–`9` taking them for
anybody working down a list rather than reading one. The sentence that says
*why* is beside them and saves as it is typed. Neither half alone is required
and both being empty is refused: a question marked answered with nothing said is
an open question that has stopped asking.

**What the question is about is above it.** The record it points at is read
whole and its opening lines are shown, the code it is scoped to is named, and
what is waiting on the answer — a task, a claim — comes from the links the
engine already holds, which is the half an asker most often forgets to write. A
question that points at nothing says so, in the column where somebody is about
to answer it: whatever is decided there is decided from memory.

**Answering archives.** The section lists what is still being asked, and the
count on its row is what is waiting on somebody — the host counts the corpus and
leaves archived records out, so this is the only way that number is true.
Nothing is lost: the record keeps every link, is found by search, and is listed
here under *Answered*.

**`chosen` is a new field**, holding the options that were taken, spelled as the
options list spells them. What was chosen is the half a list can show and a
reader can count; the prose beside it is the half that says why. It is written
by whoever answers and never by whoever asks, and it does not disturb a record
written before it existed — a question with nothing in it reads as a question
nobody has answered, which is what it is.

**The prompt now says how to ask one.** The title is the question and ends in a
question mark, the body says what is waiting and what each option costs, and
`references` says what it is about. A question is read by somebody who was not
in the conversation that raised it and cannot ask a follow-up; the panel beside
it names what is missing, in the same words.

## 1.0.0

Five kinds of claim about a project, and what to tell an agent about writing
them. No code: a vocabulary and a prompt reach a project without a line of the
package being executed.
