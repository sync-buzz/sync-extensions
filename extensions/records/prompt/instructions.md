# Records

The window onto everything the project holds, by the type it was written as.
It publishes no kinds of its own: what it shows is the whole corpus, whoever
brought it.

Nothing here is called by an agent — it is a section a person browses. What is
worth knowing is where its edges are, because both of them are edges you will
meet.

**You cannot create a type.** Types are not on this surface: a kind with no
definition is refused by the engine, and the definition is published by a
package or made by a person in this section. So when the record you want to
write has no kind that fits, that is a sentence to say out loud — *this project
has no kind for X; the section Records is where one is made* — and not a
reason to force the record into the nearest kind that will accept it. A
decision filed as an observation is wrong in the one place nobody will look for
the mistake.

**A folder is a name a person chose.** Where a folder has a record describing
it, that description is what belongs there — read it before filing into it, and
file into what exists rather than making a neighbour of it with a slightly
different name.
